Methodology and limitations

            
What this page does—and does not—claim

          

        

        

          

            
Matched work

            

              Both arms use the official checkpoint provenance, one deterministic tensor, the raw detection head, FP32
              model I/O, no NMS, and one exact GPUDevice. NCHW→NHWC input conversion and the known TFLite export's box
              channel ×640 semantic normalization occur after/before inference and outside timing.
            

          

          

            
Real synchronization

            

              Each sample includes runtime execution and explicit CPU output readback. Model fetch, hashing,
              compilation, first inference, input layout conversion, and result rendering are outside steady-state
              samples.
            

          

          

            
Delegation gates

            

              ORT sets session.disable_cpu_ep_fallback=1. LiteRT.js must retain accelerator=webgpu and
              report isFullyAccelerated=true. A hybrid result is rejected.
            

          

          

            
FP32 evidence

            

              LiteRT.js receives gpuOptions.precision=fp32. LiteRT.js has no post-compilation precision
              query, so the request echo and output parity are reported rather than overstating introspection.
            

          

          

            
ORT engine

            

              This page selects the native C++ WebGPU EP compiled to Asyncify WASM. Optional
              ?graphCapture=1 re-encodes saved dispatch records with stable external I/O; it never
              resubmits a WebGPU command buffer.
            

          

          

            
Browser requirements

            

              Use current Chrome or Edge on HTTPS or localhost. Model URLs require CORS. The benchmark uses unthreaded
              LiteRT.js and ORT with one WASM thread, so cross-origin isolation is not required.
            

          

        

        

          

            
Native Intel result is blocked—not a verdict

            

              LiteRT 2.1.6 on Windows selected TITAN V despite its public preferred-device selector; direct Intel device
              injection crashed. ORT was proven on Intel UHD 770, but no native Intel win, tie, or loss is reported.
